# Faro · overlay para AION 2

Descargas de **Faro**, un overlay para AION 2: medidor de daño, timers de eventos y jefes, Botín, Enemigos cerca, PvP,
builds, mapa y más. Proyecto de un jugador, **no oficial**: no tiene relación con NCSOFT.

## Instalar

1. Instalá **[Npcap](https://npcap.com/#download)** (gratis). Faro lo usa para leer el combate.
   En el instalador marcá «WinPcap API-compatible Mode».
2. Bajá `Faro-Setup-x.y.z.exe` de la última versión en [Releases](../../releases/latest) y abrilo.
   - Windows puede mostrar «Windows protegió su PC», porque el instalador todavía no está firmado.
     Tocá **Más información → Ejecutar de todos modos**.
3. Abrí AION 2. Faro aparece sobre el juego; la barra de arriba abre cada panel.

## Actualizaciones

Faro se fija solo si hay una versión nueva, la baja y avisa. También podés buscarla en **Ajustes → Versión**.
Tus datos (personajes, historial, ajustes) no se tocan al actualizar. La primera vez que lo abrís actualizado,
te muestra qué hay de nuevo.

## Importante

- Faro **lee el tráfico de red que el juego manda a tu PC**. No toca el juego, no lee su memoria ni rompe ningún cifrado.
  Igual, las reglas de NCSOFT no autorizan herramientas de terceros: **usarlo es un riesgo para tu cuenta**.
- El motor de daño es un fork con licencia GPL-3.0 de un medidor de código abierto; su código está en
  [faro-motor](https://github.com/Franco-Schillaci/faro-motor).
